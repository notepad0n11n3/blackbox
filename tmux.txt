### split-window  division de pantalla

							 -h        — división horizontal (paneles lado a lado | )
							 -v        — división vertical   (paneles apilados -- )
							 -p N      — tamaño en porcentaje (ej. -v -p 30 → el nuevo ocupa 30%)
							 -l N      — tamaño en líneas/celdas (-h -l 80 → ancho fijo de 80)
							 -t target — qué panel/ventana dividir ( -t 2 o -t "ReadY:$nam" )
							 -c dir    — directorio de trabajo del nuevo panel
							 -f        — tamaño completo ( divisio fuerte % "  ....<3 <3 <3 )
							 -d        — no cambiar el foco al panel nuevo
							 -b        — crear el panel antes (a la izquierda/arriba)

				::: split-window -h -p 40
				::: split-window -v -l 10
